## アプリ概要

このアプリは、Javaで作成したRPG風のバトルゲームです。  
ユーザーはヒーローや魔法使いなどのキャラクターを選び、モンスターと戦います。  

## 使用技術

- Java（オブジェクト指向）
- Eclipse（開発環境）

## 制作目的

Javaの基礎とオブジェクト指向プログラミングの理解を深めるために作成しました。

## 主な機能

- キャラクター選択と作成
- バトルロジック（攻撃、防御、スキル使用）
- 継承やポリモーフィズムを活かしたクラス設計

## こだわった点

Hero、Magician、Monsterのクラスをベースに、Superクラスを継承させて柔軟な拡張ができるように設計しました。
